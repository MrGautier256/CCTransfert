## Nouveautés

### Version autonome : exe Windows et binaire Linux

Plus besoin de Python :

- **Windows** : téléchargez `CCTransfert-1.1.0-windows-x64.exe` et double-cliquez dessus. L'interface s'ouvre sans fenêtre de console. `cctransfert-cli-1.1.0-windows-x64.exe` sert pour la ligne de commande.
- **Linux** : `CCTransfert-1.1.0-linux-x86_64`. Sans argument il ouvre l'interface ; avec des arguments, c'est la ligne de commande.

Au premier lancement de l'exe, Windows SmartScreen peut afficher « Windows a protégé votre ordinateur », car l'exe n'est pas signé : cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.

### Icônes sur le bureau et dans le menu

Le nouvel onglet **Réglages** propose deux cases, « Icône sur le bureau » et « Raccourci dans le menu Démarrer » (ou « menu des applications » sous Linux), qu'on coche ou décoche. Avec la version autonome, l'exécutable est copié dans un dossier stable : les raccourcis restent valides si l'on supprime le fichier téléchargé.

### Dupliquer une session

Le bouton **Dupliquer…** (ou `CCTransfert duplicate`) crée une copie indépendante d'une session sur la même machine :

- elle reçoit un nouvel ID et garde l'historique et le rewind ;
- elle va dans le même dossier ou dans un autre ;
- elle prend un nouvel intitulé, « (copie) » par défaut.

L'original n'est pas touché, et la copie s'annule depuis l'onglet Historique. L'import accepte aussi un nouvel intitulé (`--title`).

### Mise à jour automatique

Au démarrage, au plus une fois par jour, CCTransfert vérifie s'il existe une nouvelle version et propose de l'installer :

- **exe, binaire Linux, pipx et uv** : la nouvelle version est installée et l'application redémarre ;
- **copie git** : l'application affiche la commande à lancer.

Chaque fichier téléchargé est vérifié avec le `SHA256SUMS.txt` de la release. La vérification est désactivable dans Réglages. `CCTransfert update` fait la même chose en ligne de commande.

### Divers

- Claude Code est trouvé même quand l'application est lancée depuis une icône, avec un `PATH` sans `~/.local/bin`.
- Sous Windows, aucune fenêtre de console n'apparaît quand l'interface lance une commande.
- Les tests tournent désormais aussi sous Windows dans la CI.

## Installation

| Système | Fichier |
|---|---|
| Windows | `CCTransfert-1.1.0-windows-x64.exe` (interface) et `cctransfert-cli-1.1.0-windows-x64.exe` (ligne de commande) |
| Linux | `CCTransfert-1.1.0-linux-x86_64` (`chmod +x`) |
| Avec Python 3.9+ | `pipx install cctransfert-1.1.0-py3-none-any.whl` |

Empreintes : `SHA256SUMS.txt`.
